# Task 4 – Data Visualization using Matplotlib (Week 2 – Day 4)

---

## Overview

This task is part of **Week 2** of the **AI/ML Fellowship Program**.  
The main purpose of this task was to understand how **data visualization** helps in analyzing datasets by presenting information in graphical form.

The focus of this task was to use **Matplotlib** to create basic visualizations that make patterns and trends easier to understand compared to raw tables.

---

## Task Objectives

The main objectives of this task are:

- To understand the importance of data visualization
- To learn how to use Matplotlib in Google Colab
- To visualize categorical and numerical data
- To analyze survival patterns in the Titanic dataset
- To add proper titles and labels to plots
- To interpret insights from visual representations

---

## Tools & Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
- Kaggle Titanic Dataset (train.csv)

---

## Dataset Description

The Titanic dataset was used for this task.  
The `train.csv` file was selected because it contains the **Survived** column required for analysis.

Important columns used:

- **Survived** – Passenger survival status  
- **Sex** – Gender of passengers  
- **Age** – Age of passengers  

---

## Visualizations Performed

### Bar Chart – Survival vs Gender

A bar chart was created to compare the number of survivors based on gender.

This visualization helps in understanding the difference in survival rates between male and female passengers.

---

### Histogram – Age Distribution

A histogram was used to visualize the distribution of passenger ages.

This helps identify which age groups were most common among the passengers.

---

### Pie Chart – Survival Percentage

A pie chart was created to show the percentage of passengers who survived versus those who did not.

This provides a clear percentage-based comparison of survival outcomes.

---

## Titles & Labels

All plots include:

- Proper graph titles
- X-axis and Y-axis labels
- Percentage labels where required

This improves clarity and makes the visualizations easier to understand.

---

## Insight

Visual representations make it easier to understand patterns compared to tables.

- Female passengers had a higher survival rate
- Most passengers belonged to young to middle age groups
- Survival percentage was clearly visible through the pie chart
