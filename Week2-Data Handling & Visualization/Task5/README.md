# Task 5 – Seaborn & Advanced Data Visualization (Week 2 – Day 5)

## Overview

This task is part of **Week 2** of the **AI/ML Fellowship Program**.  
The main purpose of this task was to explore **advanced data visualization techniques** using the **Seaborn library** and understand how visualizations help in identifying **patterns, trends, and relationships** within data.

In this task, the **Titanic dataset** was used to analyze passenger survival patterns.  
Seaborn was chosen because it provides high-level, visually appealing statistical plots that make data analysis easier and more intuitive.

---

## Task Objectives

The main objectives of this task are:

- To understand the role of advanced data visualization in data analysis  
- To learn how to use **Seaborn** in **Google Colab**  
- To visualize relationships between different features of a dataset  
- To analyze survival patterns in the Titanic dataset  
- To identify important factors affecting passenger survival  
- To interpret insights using visual plots and graphs  

---

## Dataset Description

The **Titanic dataset** was used for this task.  
The dataset contains information about passengers such as:

- Survival status  
- Passenger class  
- Age  
- Fare paid  
- Gender and other attributes  

The dataset was loaded using the `train.csv` file, which includes labeled survival data.

---

## Tools & Libraries Used

The following tools and libraries were used:

- **Google Colab** – for code execution  
- **Pandas** – for data loading and manipulation  
- **Matplotlib** – for basic plotting support  
- **Seaborn** – for advanced and statistical data visualization  

---

## Visualizations Performed

The following Seaborn visualizations were created during this task:

### Count Plot
- Survival count of passengers  
- Survival comparison across passenger classes  

### Box Plot
- Survival vs Fare  
- Survival vs Age  

### Heatmap
- Correlation matrix of numerical features  

These plots helped in understanding how different variables are related to survival outcomes.

---

## Correlation Analysis

A **correlation matrix** was generated using numerical features of the dataset.  
The matrix was visualized using a **Seaborn heatmap**, which clearly showed the strength and direction of relationships between variables such as:

- Survival  
- Passenger class  
- Fare  
- Age  

---

## Key Insights

The following insights were observed from the visual analysis:

- Passenger **class** has a strong impact on survival  
- Passengers in **higher classes** had better chances of survival  
- **Fare** is a strong indicator of survival, as higher fare passengers survived more  
- Younger passengers showed slightly better survival trends  
- Class and fare are more influential than age alone
