# Task 2 – Dataset Basics & Data Handling (Week 2 – Day 1)

## Overview
This task is part of **Week 2** of the **AI/ML Fellowship Program**.  
The main purpose of this task is to understand the basics of datasets and learn how to load, explore, and analyze data using Python and Pandas in Google Colab.

The focus of this task was to build a strong foundation in data understanding before moving toward data cleaning, visualization, and machine learning concepts.

---

## Task Objectives
The main objectives of this task are:

- To understand what a dataset is and how it is structured  
- To learn how to use **Google Colab** for data analysis  
- To load a CSV dataset using the **Pandas** library  
- To explore the dataset using basic Pandas commands  
- To understand different data types (Numerical & Categorical)  
- To identify the target column for analysis  

---

## Tools & Technologies Used
- **Google Colab** – Online Jupyter Notebook environment  
- **Python** – Programming language  
- **Pandas** – Data handling and analysis library  
- **Titanic Dataset** – CSV dataset used for practice  

---

## Dataset Used
- **Dataset Name:** Titanic – Machine Learning from Disaster  
- **Source:** Kaggle  
- **File Format:** CSV (`train.csv`)  

The dataset contains information about passengers such as age, gender, class, fare, and survival status.

---

## Steps Performed

### 1. Google Colab Setup
- Opened Google Colab
- Created a new Jupyter Notebook
- Renamed the notebook for Week 2 – Day 1 work

---

### 2. Dataset Download & Loading
- Downloaded the Titanic dataset from Kaggle
- Extracted the CSV file
- Uploaded the dataset to Google Colab
- Loaded the dataset using Pandas `read_csv()` function

---

### 3. Dataset Exploration
The following Pandas commands were used to explore the dataset:

- `head()`  
  - To view the first few rows of the dataset  

- `info()`  
  - To understand rows, columns, data types, and missing values  

- `describe()`  
  - To view statistical summary of numerical columns  

---

### 4. Understanding Data Types
- **Numerical Data:**  
  - Age, Fare, SibSp, Parch  

- **Categorical Data:**  
  - Sex, Pclass, Embarked, Name  

This helped in understanding how different types of data are handled during analysis.

---

### 5. Target Column Identification
- **Target Column:** `Survived`  
  - `0` → Passenger did not survive  
  - `1` → Passenger survived  

This column is important for future analysis and prediction tasks.
