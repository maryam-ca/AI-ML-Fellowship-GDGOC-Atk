| Task 6 | EDA on Titanic | Comprehensive analysis with insights |

### **Major Task: Exploratory Data Analysis (EDA) on Titanic Dataset**

- **Data Loading and Inspection**
  - Load dataset using Pandas
  - Examine structure with `.info()`, `.describe()`, `.head()`
  - Identify data types and missing values

- **Data Cleaning and Preprocessing**
  - Handle missing values in Age, Cabin, Embarked
  - Convert categorical variables (Sex, Embarked) to numerical
  - Create new features (FamilySize, IsAlone)

- **Visualization and Analysis**
  - Survival rates by gender, class, age
  - Correlation analysis with heatmaps
  - Distribution plots for numerical features
  - Feature importance insights

- **Key Insights**
  - Women had significantly higher survival rates (74%) vs men (19%)
  - First-class passengers had highest survival rate (63%)
  - Children under 10 had better survival chances
